# Promotional thumbnails

The October 24, 2026 batch is under `Thumbnails/2026-10-24/`. Its `final/` folder contains fifteen 1920 x 1080 PNG promotional illustrations for Hotel Oddities, generated with the built-in image tool from real Studio scenery, enemy, and avatar screenshots.

The batch README documents the cast-reference workflow, temporary edit-time staging helper, cleanup, and exact-size export. `prompts.json` preserves the art direction and individual briefs; `manifest.json` maps final images to references and records visual review; `gallery.html` provides a local comparison gallery. These files do not live in the synced Roblox service containers and do not execute in the game.

A second set of fifteen additional thumbnails, numbered 16–30, is under `Thumbnails/2026-10-24-muted/`. It uses muted colors, threatening proximity and uncanny encounters while retaining readable faces and shadow detail. It reuses the first batch's separate cast/location references and has its own prompts, manifest, final PNG folder and comparison gallery. See its README for the generation and export workflow.

The November 8, 2026 set is under `Thumbnails/2026-11-08/`: fifty new 1920 × 1080 RGB PNG thumbnails numbered 01–50. It deliberately varies medium, composition, palette, location, entity and protagonist, including cinematic renders, graphic prints, VHS, clay miniatures, painted posters, charcoal, low-poly and pixel art. Hythe55 appears without crowns or shoulder cats and with an upright, centered, reduced yellow top hat. The set reuses the October cast/location photography from Hotel Oddities place 107541011814957; this batch makes no Studio or gameplay changes. Its README, exact prompt set, source/review records, manifest, local filterable gallery, export script and archive verifier preserve the production workflow. The delivery zip contains all fifty final PNGs and their browsing/provenance files and is sent to D through Taildrop.
